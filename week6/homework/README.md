# Week 6 Homework: Prompt Engineering Audit

## Task

I help licensed family child care providers in California advertise their openings on
MyTeachers123.com. For each provider I make a price sheet: CDSS license number, program name,
monthly prices by age, address, phone numbers, and a QR code linking to
`https://myteachers123.com/<license number>`. These used to be images; now they must be HTML pages.

The recurring LLM task: **read a provider's price-list flyer (image) and return validated JSON**
(license number, names, price unit, price lines with age ranges converted to months, address,
phones). Code then turns the JSON into the HTML page and QR code.

- Real inputs: 5 price-list flyers from my work (`data/flyers/`), with my expected answers in `data/inputs.json`.
- Adversarial inputs: 3 edited flyers (`data/adversarial/`) targeting one failure mode each.
- Few-shot examples: 2 fictional flyers made with my HTML template (`data/examples/`).

## Files

| File | Contents |
|---|---|
| `notebook.ipynb` | Parts 1-3: five prompt variations, scoring, results table, failure analysis, LangChain chain, HTML output |
| `analysis.md` | Written analyses for Parts 1, 2 and 3 |
| `capstone_pitch.md` | Capstone topic pitch |
| `output/` | HTML price sheets generated by the LangChain chain |

## How to run

1. Open `notebook.ipynb` in Google Colab (or Jupyter) from this folder.
2. Add `OPENAI_API_KEY` (Colab: Secrets panel). Model: `gpt-5.4-mini`.
3. Run all cells. Without a key the notebook runs in MOCK mode (canned answers) to check the code only.
